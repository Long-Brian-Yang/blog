## 使い方
1. [自己分析](self-assessment.md)：経験・強み・価値観を言語化

3. [企業・応募管理](company-tracker.md)：情報源・締切・応募履歴を管理
4. [活動ログ](activity-log.md)：調査・面談・気づきを時系列で残す
5. [ロードマップ](roadmap.md)：今週から入社までの行動を設計

## 探索方針
R&D、材料・化学・エネルギー、IT・AI・計算科学、コンサルティング・総合職を同じ出発点から比較する。職種と業界は別の軸で考える。研究職だけに絞らず、博士人材が活躍する技術職・事業職も検討する。

## 判断の原則
- **事実**（公式募集要項）・**推測**（適性の仮説）・**感想**（興味）を分ける。
- 会社名より、実際の職務・育成環境・働き方・評価制度を重視する。
- 比較基準は、仕事内容、専門との接続、成長、待遇、勤務地、言語、裁量、研究自由度、事業インパクト。
- 公開リポジトリに個人情報、未公開研究、選考機密、連絡先を保存しない。
