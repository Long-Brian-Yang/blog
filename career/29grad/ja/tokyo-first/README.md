## 福利厚生・待遇の評価軸
| 項目 | 調査ポイント |
|---|---|
| 基本給 | 博士初任給・月給・固定残業代の内訳 |
| 賞与 | 年間回数・算定条件・変動性 |
| 住宅 | 家賃補助・借上社宅・寮・適用年齢と年限 |
| 勤務 | フレックス・裁量労働・在宅勤務・出社頻度 |
| 休暇 | 年間休日・有休付与・取得実績・特別休暇 |
| 手当 | 通勤費・残業代・家族手当・研究費・研修費 |
| 長期 | 退職金・確定拠出年金・持株会・ストックオプション |
| 配属 | 初任地・研究所・転勤・海外異動・ジョブ型採用 |
| 言語 | 日本語要件・英語での面接/勤務の可否 |

**比較上の注意**：額面年収だけでなく、住宅補助や固定残業代、勤務地、労働時間、株式報酬のリスクを分けて比較する。金額が未確認の会社に推定給与を記入しない。
