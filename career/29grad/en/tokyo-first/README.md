# Tokyo-first Employer Research — Compensation and Benefits

Updated 2026-10-27. **Exploratory profiles only; neither Class of 2029 eligibility nor compensation packages have been verified.** Headquarters and actual worksite are separate facts.

## Geographic preferences
1. Tokyo 23 wards; 2. other Tokyo municipalities; 3. commutable Kanagawa/Chiba/Saitama; 4. elsewhere only for exceptional opportunities.

## Benefits comparison rubric
| Dimension | What to verify |
|---|---|
| Base pay | Doctoral starting salary, monthly salary, included overtime |
| Bonuses | Frequency, formula, variability |
| Housing | Rent subsidy, company apartment, dorm, age/tenure limits |
| Work model | Flex time, discretionary labor, remote work, office days |
| Leave | Annual holidays, paid leave, actual usage, special leave |
| Allowances | Transport, overtime, dependents, research/training |
| Long term | Retirement, pension, employee shares, stock options |
| Placement | Initial office/lab, relocation, overseas moves, role-based hiring |
| Language | Japanese requirements, English interviews and work |

**Comparison rule:** Do not invent salaries. Compare housing, included overtime, hours, worksite, and equity risk separately from nominal annual compensation.
