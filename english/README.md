# English Learning

A date-based English learning log focused on **natural output, speaking fluency, academic communication, and advanced expression**.

## How this repository works

Each lesson is kept in **one self-contained Markdown file**. Vocabulary, grammar, spoken English, and output practice stay together with the original topic so the lesson can be studied from top to bottom.

Typical flow:

**Reading / Context → 中文理解 → Vocabulary & Chunks → Grammar & Usage → Natural Spoken English → Active Output → Suggested Answers → Retelling / Review**

The goal is not to build a traditional textbook. It is to preserve useful English in the context where it was learned and gradually turn passive knowledge into language that can be reused naturally.

## Structure

```text
english/
├── README.md
└── daily/
    ├── 2024/
    ├── 2025/
    └── 2026/
```

File naming:

`YYYY-MM-DD_topic.md`

## Progression

The material currently covers four increasingly important areas:

**Professional communication**  
Research requests, internship replies, and concise workplace English.

**Academic identity**  
CV writing, academic self-introduction, and explaining a research journey.

**Technical communication**  
Scientific presentations, methods, results, and interview explanations.

**Advanced spontaneous output**  
Expressing opinions, handling abstract topics, using natural chunks, and speaking without translating word by word.
