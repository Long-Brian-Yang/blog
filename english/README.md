# English Learning

A date-based English learning log focused on **natural output, speaking fluency, academic communication, technical interviews, and advanced expression**.

## How this repository works

Each lesson is kept in **one self-contained Markdown file**. Reading, Chinese explanation, vocabulary/chunks, grammar, natural spoken English, output practice, answers, and retelling stay together.

Typical lesson:

**Reading / Context → 中文理解 → Vocabulary & Chunks → Grammar & Usage → Natural Spoken English → Expression Upgrade → Active Output → Suggested Answers → Retelling → Notes**

File naming: `YYYY-MM-DD_topic.md`
